# ASHEN VEIL

RPG táctico por turnos en 2D-HD, con construcción de mazo y artilugios. Tras la ruptura del velo que protegía al mundo, un Despierto descubre los secretos que las religiones ocultaron.

**Godot 4 · GDScript**

## Estructura del repositorio

| Carpeta | Contenido |
|---|---|
| [ashen-veil/](ashen-veil/) | Proyecto de Godot |
| [jugabilidad/](jugabilidad/) | Diseño de jugabilidad: combate, héroe, cartas, artilugios, enemigos, mundo, arquitectura y flujo de assets |
| [consolidacion/](consolidacion/) | Biblia narrativa: canon, reparto, Concordancia, el Arca, el Diablo, las Huestes y los arcos de la campaña |
| [openspec/](openspec/) | Especificaciones y cambios del código (OpenSpec) |
| `escritura-1.md`, `escritura-2.md` | Borradores originales del lore |

## Requisitos

- Godot 4 (edición estándar, no .NET)
- Git LFS (`git lfs install`) para imágenes, modelos y audio
